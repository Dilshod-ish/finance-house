# Architecture Decision Records

Qaytarish qimmat bo'lgan har bir qaror shu yerga yoziladi. Format qisqa:
kontekst, qaror, oqibatlar, ko'rib chiqilgan alternativalar.

Fayl nomi: `NNNN-qisqa-sarlavha.md`, ketma-ket raqamlanadi. ADR o'chirilmaydi —
eskirsa `Superseded by ADR-NNNN` deb belgilanadi.

Til: **o'zbekcha (lotin)**, fayl nomi ham. Identifikatorlar, ustun nomlari, SQL,
kod bloklari va invariant nomlari (`I1`, `journal_line`, `article.flow_type`)
o'z holida qoladi — faqat matn o'zbekcha. Kod, kommit xabarlari va koddagi
izohlar inglizcha qoladi (CLAUDE.md §11).
